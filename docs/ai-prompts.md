# AI Промпти — Референс

Цей файл описує логіку кожного промпту.
Самі промпти живуть у /lib/ai/prompts/

---

## analyze-onboarding.ts

**Вхід**: відповіді трьох мікро-задач + діалогу цілі
**Вихід**: JSON з профілем А+Б

```typescript
// Профіль А — Мотивація і енергія
{
  motivation_vector: 'approach' | 'away_from',  // до мети чи від загрози
  energy_source: 'achievement' | 'recognition' | 'connection' | 'mastery',
  autonomy_level: 1-5,  // 1=потребує структури, 5=хоче повної автономії
  time_horizon: 'days' | 'weeks' | 'months' | 'years'
}

// Профіль Б — Когнітивний стиль
{
  depth_vs_breadth: 1-5,  // 1=широко, 5=глибоко
  ambiguity_tolerance: 1-5,  // 1=потребує структури, 5=пришвидшується в хаосі
  processing_style: 'analytical' | 'intuitive',
  learning_pace: 'fast' | 'medium' | 'deep'
}
```

**Принцип**: аналізуємо поведінку (темп, вибори, стиль) — не те що людина сказала про себе.

## generate-module.ts

**Вхід**: профіль А+Б + домен + ціль + контекст попередніх модулів (якщо є)
**Вихід**: JSON з трьома актами

```typescript
{
  hook: {
    text: string,           // 200–300 слів, персональний місток
    personal_reference: string  // конкретна деталь з онбордингу
  },
  core: {
    sections: Array<{
      text: string,         // 400–600 слів
      pause?: {             // активна пауза після блоку
        question: string,
        type: 'reflection' | 'application' | 'recall'
      }
    }>,
    sources: Array<{
      title: string,
      author: string,
      type: 'book' | 'article' | 'research',
      relevance: string     // чому це джерело важливе для цієї теми
    }>
  },
  action: {
    task: string,           // одне конкретне завдання для сьогодні
    reflection_prompt: string  // питання для рефлексії після
  }
}
```

**Принципи**:
- Гачок завжди з персональним контекстом з онбордингу
- Активні паузи: retrieval practice, не перевірка знань
- Дія: конкретна, виконувана сьогодні, не "прочитай ще"

## detect-skills.ts

**Вхід**: опис події + відповіді на уточнюючі питання
**Вихід**: JSON з пропозицією скілів

```typescript
{
  clarifying_questions: string[],  // 2–3 питання для уточнення
  suggested_skills: Array<{
    name: string,           // коротка назва скілу (2–4 слова)
    evidence: string,       // конкретне підтвердження з події
    context_tag: string     // категорія: work | personal | creative | leadership
  }>
}
```

**Принцип дзеркала**: пропонуємо тільки те що людина описала в події.
Ніколи не додаємо скіли які "мабуть є" але не підтверджені словами людини.

## generate-retrospective.ts

**Вхід**: всі дані за 30 днів — модулі, check-in відповіді, скіли, поведінковий трекінг
**Вихід**: наративний текст (не статистика)

**Структура ретроспективи**:
1. Що ми помітили в тому як ти навчаєшся (з поведінкових даних)
2. Що змінилось у твоїх діях (з check-in відповідей)
3. Що розкрилось у твоїх скілах (з архіву подій)
4. Куди природньо рухається твій інтерес (з вибору тем)

**Тон**: доброзичливо, конкретно, через факти а не оцінки.
Ніколи: "ти не виконав X", "у тебе є проблема з Y".
Завжди: "ми помітили що...", "схоже тебе особливо цікавить...", "ти тричі повертався до..."
