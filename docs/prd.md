# Lume — PRD + User Journey · MVP

---

## Скоуп MVP

### Будуємо
- Онбординг: 3 мікро-задачі + діалог цілі
- AI-генерація триактного модуля (Claude Sonnet)
- Трекінг поведінки всередині модуля
- Карта особистості: блоки А+Б одразу, блок В після 4 тижнів
- Архів подій і карта скілів з рівнями
- Check-in через 7 і 14 днів
- 30-денна ретроспектива (AI-генерований наратив)
- Посилання на першоджерела з нагадуванням після модуля
- Token-based підписка через Lemon Squeezy

### Не будуємо зараз
- Менторський дашборд B2B
- Коучингові питання AI (блок Г карти) — потребує окремої проробки
- Kindle інтеграція
- Соціальні функції

## User Journey — повний шлях

### Фаза 0 — Перший дотик
Лендінг. Позиціонування: платформа навчання, персональна, результат за тиждень.
CTA: "Почати безкоштовно".

### Фаза 1 — Онбординг (7–12 хвилин)

**Крок 1 — Три мікро-задачі**

Задача 1 — Розуміння тексту:
- Уривок 150–200 слів з незнайомої теми
- 2 питання на розуміння + 1 відкрите: "що здалось найважливішим?"
- Система вимірює: час читання, чи перечитував, стиль формулювання

Задача 2 — Рішення в невизначеності:
- Ситуація без правильної відповіді (менеджерський сценарій)
- 3 варіанти + поле "інше"
- Система вимірює: який варіант, чи написав своє, швидкість рішення

Задача 3 — Пріоритизація:
- 5 задач на тиждень → розташуй за важливістю
- Поле: "чому саме так?"
- Система вимірює: логіку (термін/вплив/делегування), горизонт мислення

**Крок 2 — Діалог цілі (4 питання максимум)**

```
Q: "Що хочеш навчитись? Розкажи своїми словами."
Q: "Навіщо це тобі саме зараз?"
Q: "Скільки часу на тиждень реально можеш виділити?"
Q: "Як тобі краще вчитись — читати, слухати, або все одно?"
```

Після: "Готуємо твій перший модуль — це займе хвилину."
Система будує: профіль А+Б, домен, ціль, формат, темп.

### Фаза 2 — Перший модуль

**Акт А — Гачок (2–3 хв)**
Персональний вступ із прив'язкою до конкретної ситуації людини.
Приклад: "Ти сказав що через місяць стаєш тімлідом..."

**Акт Б — Ядро (15–30 хв)**
Контент у форматі під профіль.
Активні паузи кожні 400–600 слів.
Посилання на першоджерела як "закладки".

**Акт В — Дія (5–10 хв)**
Одне конкретне мікро-завдання для сьогодні.
Поле рефлексії після.

**Трекінг під час модуля:**
- Час на кожному блоці
- Повтори і перечитування
- Чи відкрив закладки
- Час на активних паузах (довжина відповіді = глибина)
- Чи виконав мікро-завдання

### Фаза 3 — Петля (дні 1–14)

- День 2: коригування наступного модуля на основі поведінки
- День 7: check-in "ти застосовував цього тижня?"
- День 14: check-in + "що змінилось у твоїх діях?"
- Фоновий spaced repetition через посилання в наступних модулях

### Фаза 4 — Карта особистості (дні 1–30+)

- День 1: профіль А+Б видно одразу після онбордингу
- День 3–5: пропозиція додати першу подію в архів
- День 28–30: перша ретроспектива (AI-наратив, не статистика)

## Фічі — деталі

### F-01 Онбординг
- Прогрес-бар зверху
- Три задачі послідовно, без пропуску
- Чат-інтерфейс для діалогу (не форма)
- Після: екран "Готуємо модуль" з анімацією 30–60 сек

### F-02 AI-генерація модуля
- Input: профіль + домен + ціль + поведінкові дані попередніх модулів
- Output: три акти з активними паузами і закладками
- Час генерації: до 30 сек
- Streaming відповіді (не чекати до кінця)

### F-03 Карта скілів
- Форма опису події (мін. 3 речення)
- 2–3 уточнюючих питання від AI
- Пропозиція 3–5 скілів → підтвердження людиною
- Рівні: 1 / 2–3 / 5–6 / 8+ підтверджень з різних контекстів
- Один скіл в одному контексті = одне підтвердження

### F-04 Check-in і ретроспектива
- День 7 і 14: email/push + форма (1 хвилина)
- День 30: AI генерує наративний звіт з усіх даних
- Тон: завжди доброзичливо, ніколи "ти не зробив X"

### F-05 Токени
- Баланс у хедері завжди
- Попередження при 20% і 5%
- Докупити: окремий flow, баланс оновлюється одразу
- Rollover: Make запускається 1-го числа, cap 50%

## Acceptance Criteria

### Онбординг
- [ ] Три задачі проходяться без технічних помилок
- [ ] Діалог зберігає відповіді і використовує їх у генерації
- [ ] Перший модуль з'являється протягом 60 сек після онбордингу
- [ ] Профіль А+Б видно в розділі "Про мене" одразу

### Модуль
- [ ] Коректно на мобільному і десктопі
- [ ] Активні паузи вшиті і зберігають відповіді
- [ ] Посилання зберігаються як закладки
- [ ] Після завершення — питання про мікро-завдання
- [ ] Трекінг пишеться в БД без помилок

### Карта скілів
- [ ] Можна додати подію і пройти діалог
- [ ] Скіл з'являється тільки після підтвердження
- [ ] Рівень оновлюється коректно

### Токени
- [ ] Баланс відображається і оновлюється після кожної AI-дії
- [ ] Попередження при 20% і 5% працюють
- [ ] Докупити — flow завершується і баланс оновлюється

## Відкриті питання

1. Яка LLM для генерації? → Claude Sonnet (визначено)
2. Як рахуються токени? → per API call, фіксована вартість per тип дії
3. Re-engagement якщо людина пропала після онбордингу?
4. Хто пише контент трьох мікро-задач? → AI-генерація з ревью
5. Перша ретроспектива — повністю AI або з ревью перших 50 юзерів?
6. Мова інтерфейсу на старті → визначити
